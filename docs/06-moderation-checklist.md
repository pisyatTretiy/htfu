# 06. Чек-лист перед отправкой на модерацию

Прогоняется дважды: на гейте фазы 2 (вертикальный срез) и на фазе 5 (перед отправкой).
Модерация занимает 3–5 рабочих дней, каждый отказ стоит полного цикла ожидания.

> **Что уже сделано в коде:** SDK за интерфейсом `IPlatform`, `LoadingAPI.ready`,
> `GameplayAPI.start/stop` (включая паузу на время рекламы и открытого магазина), остановка звука
> при потере фокуса, автоопределение языка, сохранение прогресса с переживанием перезагрузки,
> отключение контекстного меню, награда за ролик строго в `onRewarded`, кулдаун полноэкранной
> рекламы, разбор незавершённых покупок при каждом запуске и списание расходуемых, скрытие
> покупок на TV, навигация стрелками пульта. Часть пунктов проверяется автотестами
> (`npm run test`, `npm run capture`).
>
> **Что нельзя проверить без черновика:** реальная работа рекламы, авторизации и облачных
> сохранений. Эти пункты закрываются только прогоном на площадке.

## Технические требования

- [ ] `index.html` в корне архива, архив ZIP, распакованный размер ≤ 100 МБ
- [ ] В именах файлов нет пробелов и кириллицы
- [ ] SDK подключён **до** вызова `YaGames.init()`
- [ ] `YaGames.init()` вызывается один раз, ошибки инициализации обрабатываются
- [ ] `ysdk.features.LoadingAPI.ready()` вызывается, когда интерфейс реально интерактивен
- [ ] `GameplayAPI.start()` / `.stop()` расставлены: старт уровня, пауза, меню, реклама,
      уход из вкладки и возврат
- [ ] Звук останавливается при потере фокуса вкладкой (`visibilitychange`, `blur`)
- [ ] Звук и геймплей на паузе во время полноэкранной рекламы, восстанавливаются после
- [ ] Прогресс сохраняется сразу после действия игрока и переживает F5
- [ ] Нет JS-ошибок в консоли на всём пути прохождения
- [ ] Нет зависаний при повороте экрана, сворачивании браузера, переключении вкладок
- [ ] Контекстное меню браузера в игровой области отключено
- [ ] Нет системного скроллбара
- [ ] Используется встроенный плеер, а не системный
- [ ] Автоопределение языка через `ysdk.environment.i18n.lang`

## Реклама

- [ ] Вся реклама вызывается только через SDK Яндекс Игр
- [ ] Нет рекламы третьих лиц и сторонних ad-SDK
- [ ] Нет собственных полноэкранных блоков и имитации видеорекламы
- [ ] Rewarded-видео добровольное, награда описана **до** запуска ролика
- [ ] Награда — дополнительный бонус, без неё игра проходится полностью
- [ ] Награда выдаётся в `onRewarded`, а не в `onClose`
- [ ] Реклама не показывается во время активного взаимодействия игрока
- [ ] Кулдаун полноэкранной рекламы ≥ 180 секунд

## Покупки (если включены)

- [ ] Товары активированы в консоли разработчика
- [x] Настроено консумирование расходуемых товаров (`consumePurchase`) — списываем **после**
      начисления: не списали — покупка вернётся при следующем запуске, и игрок получит своё
- [x] Незавершённые покупки обрабатываются **при каждом запуске** (`getPurchases`); выдача идёт
      одним и тем же путём и при покупке, и при разборе списка
- [x] Внешние платёжные системы отсутствуют
- [x] Магазин скрыт на TV-устройствах (`deviceInfo.isTV()`)
- [x] Незнакомый товар не списывается: пусть дождётся версии, которая умеет его выдать

## Устройства

- [ ] Мобильные: полноэкранный режим, управление только жестами, одна рука
- [ ] Мобильные: клавиатура появляется автоматически при вводе текста
- [ ] Десктоп: управление мышью или клавиатурой по умолчанию
- [ ] Десктоп: длинная сторона активного поля ≤ 2× короткой
- [ ] Десктоп: не используются зарезервированные системные горячие клавиши
- [x] TV: полное прохождение стрелками пульта, обработаны OK и Back
- [ ] Элементы UI не обрезаются и не выходят за экран на всех разрешениях

## Контент

- [ ] Возрастной тег соответствует содержанию (целевой — **6+**)
- [ ] Нет крови и визуальных страданий, нет жестокости к животным
- [ ] Нет азартных игр, ставок, лотерей, вывода реальных денег
- [ ] Нет алкоголя и табака
- [ ] Нет политики, войн, религиозных образов, эзотерики
- [ ] Нет эротики и порнографии
- [ ] Нет заимствованных ассетов — все права на материалы принадлежат команде
- [ ] Игра не является копией игры из каталога, название уникально
- [ ] Основной контент занимает ≥ 10 минут
- [ ] Тексты без орфографических ошибок и мата, не вводят игрока в заблуждение
- [ ] Локализация на все заявленные языки полная (ru + en)

## Ссылки и внешние ресурсы

- [ ] Нет ссылок на внешние сайты, сторы и соцсети
- [ ] Нет автоматических редиректов
- [ ] Переходы на другие игры — только через SDK каталога

## Промо-материалы

- [ ] Скриншоты показывают реальный геймплей, занимающий ≥ 70 % кадра
- [ ] Иконка и обложка не являются скриншотами игры
- [ ] Название одинаково во всех материалах и на всех языках
- [ ] Нет повторяющихся символов для обхода проверок
- [ ] Нет элементов системного интерфейса и логотипов сервиса на изображениях
- [ ] Медиа без визуальных артефактов

## После публикации

- [ ] Рейтинг игры отслеживается ежедневно (≤ 30 в течение 3 недель → снятие с публикации)
- [ ] Настроен мониторинг JS-ошибок на живой аудитории
- [ ] Воронка первых 10 минут снимается аналитикой и разбирается еженедельно
