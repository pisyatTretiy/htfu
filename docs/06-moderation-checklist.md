# 06. Чек-лист перед отправкой на модерацию

Прогоняется дважды: на гейте фазы 2 (вертикальный срез) и на фазе 5 (перед отправкой).
Модерация занимает 3–5 рабочих дней, каждый отказ стоит полного цикла ожидания.

> **Что уже сделано в коде:** SDK за интерфейсом `IPlatform`, `LoadingAPI.ready`,
> `GameplayAPI.start/stop` (включая паузу на время рекламы и открытого магазина), остановка звука
> при потере фокуса, автоопределение языка, сохранение прогресса с переживанием перезагрузки,
> отключение контекстного меню, награда за ролик строго в `onRewarded`, кулдаун полноэкранной
> рекламы, разбор незавершённых покупок при каждом запуске и списание расходуемых, скрытие
> покупок на TV, навигация стрелками пульта. Часть пунктов проверяется автотестами
> (`npm run test`, `npm run capture`).
>
> **Что нельзя проверить без черновика и живой аудитории (осталось четыре пункта):** товары
> активированы в консоли разработчика, ежедневное отслеживание рейтинга, мониторинг JS-ошибок на
> живых игроках и разбор воронки первых десяти минут. Всё остальное в этом файле закрыто кодом и
> проверяется `npm run test`, `npm run capture` и `npm run zip`.

## Технические требования

- [x] `index.html` в корне архива, архив ZIP, распакованный размер ≤ 100 МБ — проверяет `npm run zip`
- [x] В именах файлов нет пробелов и кириллицы — проверяет `npm run zip`
- [x] SDK подключён **до** вызова `YaGames.init()` — загрузка тегом в `platform/index.ts`
- [x] `YaGames.init()` вызывается один раз, при ошибке игра уходит на локальную заглушку
- [x] `ysdk.features.LoadingAPI.ready()` вызывается после первого готового кадра
- [x] `GameplayAPI.start()` / `.stop()` расставлены: старт, панели, реклама, уход из вкладки
      и возврат
- [x] Звук останавливается при потере фокуса вкладкой (`visibilitychange`, `blur`, `pagehide`)
- [x] Звук и геймплей на паузе во время полноэкранной рекламы, восстанавливаются после
- [x] Прогресс сохраняется сразу после действия игрока и переживает F5 — проверяет `npm run capture`
- [x] Нет JS-ошибок в консоли на всём пути прохождения — прогон бота падает на любой ошибке
- [x] Нет зависаний при переключении вкладок и потере контекста WebGL; поворот экрана
      обрабатывается тем же `resize`, но проверен только в эмуляции
- [x] Контекстное меню браузера в игровой области отключено
- [x] Нет системного скроллбара — `overflow: hidden` и `overscroll-behavior: none`
- [x] В сборке нет отладочных наложений: HUD разработчика скрыт и открывается только по
      `?debug=1` или клавише `H`
- [x] Видео в игре нет вовсе
- [x] Автоопределение языка через `ysdk.environment.i18n.lang` — покрыто тестом

## Реклама

- [x] Вся реклама вызывается только через SDK Яндекс Игр — вне `YandexPlatform` обращений нет
- [x] Нет рекламы третьих лиц и сторонних ad-SDK
- [x] Нет собственных полноэкранных блоков и имитации видеорекламы
- [x] Rewarded-видео добровольное, награда написана на самой кнопке
- [x] Награда — дополнительный бонус, без неё игра проходится полностью
- [x] Награда выдаётся в `onRewarded`, а не в `onClose`
- [x] Полноэкранная — только при переезде между локациями, баннер — только в панелях
- [x] Кулдаун полноэкранной рекламы ≥ 180 секунд — покрыто тестом, отсчёт с начала сессии

## Покупки (если включены)

- [ ] Товары активированы в консоли разработчика — **только на площадке**
- [x] Настроено консумирование расходуемых товаров (`consumePurchase`) — списываем **после**
      начисления: не списали — покупка вернётся при следующем запуске, и игрок получит своё
- [x] Незавершённые покупки обрабатываются **при каждом запуске** (`getPurchases`); выдача идёт
      одним и тем же путём и при покупке, и при разборе списка
- [x] Внешние платёжные системы отсутствуют
- [x] Магазин скрыт на TV-устройствах (`deviceInfo.isTV()`)
- [x] Незнакомый товар не списывается: пусть дождётся версии, которая умеет его выдать

## Устройства

- [x] Мобильные: полноэкранный режим, управление одним пальцем, второго стика нет
- [x] Ввода текста в игре нет
- [x] Десктоп: мышь и клавиатура (пробел, стрелки, R)
- [x] Десктоп: длинная сторона активного поля ≤ 2× короткой — поле ограничивается и центрируется, проверяет бот
- [x] Десктоп: не используются зарезервированные системные горячие клавиши
- [x] TV: полное прохождение стрелками пульта, обработаны OK и Back
- [x] Элементы UI не обрезаются и не выходят за экран — бот проверяет 360 px и 2560 px

## Контент

- [x] Возрастной тег соответствует содержанию (целевой — **6+**)
- [x] Нет крови и визуальных страданий: улов «усмиряют», а не убивают
- [x] Нет азартных игр, ставок, лотерей, вывода реальных денег: содержимое покупок детерминировано
- [x] Нет алкоголя и табака
- [x] Нет политики, войн, религиозных образов, эзотерики
- [x] Нет эротики и порнографии
- [x] Нет заимствованных ассетов: ни одной картинки и ни одного звукового файла в репозитории — всё считается кодом
- [x] Игра не является копией игры из каталога, название уникально
- [x] Основной контент занимает ≥ 10 минут: пять локаций, 52 вида, цепочка заданий, боссы
- [x] Тексты без орфографических ошибок и мата, не вводят игрока в заблуждение
- [x] Локализация полная (ru + en) — покрыто тестом и прогоном бота на английской вкладке
