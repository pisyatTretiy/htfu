## Завязка

Игрок с друзьями выпивает на катере, врезается в необитаемый остров и вынужден научиться
рыбачить, чтобы заработать на возвращение домой. Тон — намеренно абсурдный, физика
преувеличенная, юмор строится на хаосе.

## Кор-луп

```
Заброс → гарантированный клёв → вываживание (физика) → добивание оружием
   → продажа (цена зависит от способа добычи) → покупка снаряжения
   → квесты и боссы → новый остров с более опасными существами
```

Разбор по элементам:

1. **Заброс и вываживание.** Физическая система: игрок кидает снасть в воду, цепляет существо и
   тянет его к берегу. Ключевая находка — **клёв гарантирован**, пока снасть в воде. Это убирает
   простой и делает ритм плотным: игрок никогда не «ждёт поплавка».
2. **Добивание.** Главный челлендж не в ловле, а в том, чтобы справиться с вытащенным существом:
   ножи, кастеты, огнестрел. **Способ добычи напрямую влияет на цену продажи** — это и есть
   скилловая надстройка над простым лупом.
3. **Экономика.** Продажа улова → деньги → удочки, оружие, обвесы, двигатели лодки. Гайды
   советуют «сфокусированные сборки» вместо распыления: апгрейд под конкретное узкое место
   (долгий бой, перезарядка под боссом, скорость перемещения).
4. **Гейтинг прогресса.** Боссы и квесты NPC открывают новые острова. Трофеи боссов (череп,
   плавник, хвост) отделены от обычного «мяса» — распространённая ошибка новичков.
5. **Коллекционирование.** У каждого вида есть редкий вариант — долгосрочная цель поверх денег.
6. **Хаос-механики.** Трюк-шоты за бонус к доходу и ставки уловом (гэмблинг на внутриигровую
   валюту) — источники «историй», которыми игроки делятся.

## Почему это работает

- **Мгновенная обратная связь.** Гарантированный клёв + физика = каждые 10–20 секунд что-то
  происходит. Идеальный ритм для коротких сессий.
- **Скилл поверх гринда.** Цена зависит от того, *как* ты добыл рыбу, а не только *что* поймал.
- **Понятная лестница целей.** Деньги (минуты) → апгрейд (десятки минут) → босс и новый остров
  (часы) → коллекция редких (десятки часов).
- **Комедийная физика.** Основной генератор виральности: клипы, скриншоты, «а смотри что было».
- **Кооп как усилитель**, а не фундамент: игра работает и в одиночку.

## Что берём в адаптацию

| Элемент оригинала | Решение для Яндекс Игр |
|---|---|
| Гарантированный клёв | **Берём как есть** — это ядро ритма |
| Физическое вываживание | **Берём**, но упрощаем до 2D-физики лески (натяжение/провис) |
| Цена зависит от способа добычи | **Берём** — переносим на «качество вылова»: точность, скорость, без обрыва лески |
| Апгрейды снасти и лодки | **Берём** — удочка, леска, катушка, приманки, мотор |
| Боссы как гейт локаций | **Берём** — 5 боссов на 5 локаций |
| Редкие варианты рыб, альбом | **Берём** — сильная долгосрочная мета |
| Трюк-шоты | **Берём** в виде бонусов за точность заброса |
| Кооп 1–4 | **Режем из MVP**, заменяем асинхронной социальностью (лидерборды, недельные турниры) |
| Алкоголь в завязке | **Режем** — мотор заглох из-за поломки, а не из-за выпивки |
| Ножи, кастеты, огнестрел | **Заменяем** на сачок, гарпун-присоску, водяную пушку, магнит |
| Убийство рыбы, кровь | **Заменяем** на «усмирение» без крови, рыба уплывает при отпускании |
| Ставки уловом (гэмблинг) | **Режем полностью** — прямой стоп на модерации для рейтингов ниже 18+ |

Обоснование правой колонки — в [02-platform-constraints.md](02-platform-constraints.md).

## Конкурентное поле в каталоге Яндекс Игр

Рыболовные игры в каталоге есть, но это в основном:
- простые «кликеры про рыбалку» без прогрессии снаряжения;
- реалистичные симуляторы с медленным темпом (ожидание поклёвки);
- аркады с одной локацией и без меты.

Свободная ниша: **быстрый аркадный луп + плотная прогрессия + коллекция + боссы**. Именно
комбинация «нет простоя между забросами» и «глубокая мета» в каталоге почти не представлена.

> ⚠️ Модерация Яндекса отклоняет **копии игр из каталога**. Оригинал How to Fish в каталоге
> отсутствует (это платная PC-игра), но название, арт-стиль, персонажей и тексты делаем
> полностью своими. Ни названия, ни ассетов, ни прямых отсылок к оригиналу.
