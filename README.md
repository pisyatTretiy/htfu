# htfu — рыболовный аркадный симулятор для Яндекс Игр

Проект по мотивам PC-игры **How to Fish** (Dazed Games, Steam, 20.08.2026) — физического
рыболовного симулятора с луп-циклом «поймал → добыл → продал → прокачался → открыл новую
локацию». Задача репозитория — адаптировать идею под платформу **Яндекс Игры**: HTML5,
мобильный трафик, жёсткие правила модерации, реклама и покупки только через SDK платформы.

> Статус: **фаза 3**. Пять локаций, пять боссов с фазовыми боями, трофеи открывают следующую
> локацию, 40 видов рыбы и 12 предметов мусора в трёх вариантах редкости, бонусы за альбом.
> Журнал — [docs/spike-log.md](docs/spike-log.md).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 — сцена воды
npm run build      # typecheck + тесты + сборка в dist/
npm run test       # тесты пула заброса и баланса боя
npm run zip        # архив для консоли Яндекс Игр + проверка требований площадки
npm run capture    # прогон заброса в Playwright: кадры в dist-shots/ + проверка консоли
```

Управление одним пальцем: **тянуть** — осмотр (он же руление крючком под водой), **удержать** —
копить силу заброса, **отпустить** — заброс, **удержать в бою** — подмотка, **тап** — действие. В бою удержание подматывает: тяните на низком
натяжении и отпускайте перед обрывом. Когда улов окажется в лодке — тапайте по нему, пока он не
разнёс снасти. Кнопка **«Снасти»** внизу открывает магазин: четыре ветки прокачки, купленное
работает сразу. После улова на несколько секунд появляется добровольное «Удвоить ×2» —
на локальной сборке это заглушка вместо ролика. Сверху — задание от NPC, рядом со «Снастями»
кнопка **«Альбом»** с пойманными видами и **«Карта»** для переезда между локациями. На десктопе дублируется пробелом, стрелками и `R`.
Отладка: `?q=low` — мобильный профиль качества, `H` — скрыть HUD, `L` — заморозить главный поток
на 250 мс для проверки устойчивости симуляции.

## Короткая версия плана

1. **Не портируем оригинал 1-в-1.** Из него берём кор-луп и комедийный хаос, вырезаем то, что не
   пройдёт модерацию Яндекса: алкоголь, азартные игры, огнестрел и жестокость к животным.
   Юмор при этом держится на механиках, а не на арте — см. [ADR-0003](docs/adr/0003-comedy-register.md).
2. **Формат:** 2.5D-сайдвью (разрез воды по вертикали), портретная ориентация на мобилках,
   управление одним пальцем. Сессия 3–6 минут, «ещё один заброс» как основной хук.
3. **Стек:** TypeScript + Three.js + Vite, вид от первого лица, собственная верле-физика лески
   как подача поверх детерминированной боевой системы. Игрок закреплён в лодке, поэтому
   управление остаётся одним пальцем — см. [ADR-0004](docs/adr/0004-first-person-3d.md).
4. **Монетизация:** rewarded-видео (×2 за улов, второй шанс, ежедневный сундук), межстраничная
   реклама между сессиями, детерминированные инаппы («без рекламы», стартовый набор).
5. **Сроки:** ~14–16 недель до релиза MVP командой 2–3 человека; вертикальный срез — к 6-й неделе.

Подробности — в документах выше.
