# «Клёв! Остров рыбака» (Hook & Home) — рыболовный аркадный симулятор для Яндекс Игр

Проект по мотивам PC-игры **How to Fish** (Dazed Games, Steam, 20.08.2026) — физического
рыболовного симулятора с луп-циклом «поймал → добыл → продал → прокачался → открыл новую
локацию». Задача репозитория — адаптировать идею под платформу **Яндекс Игры**: HTML5,
мобильный трафик, жёсткие правила модерации, реклама и покупки только через SDK платформы.

> Статус: **фаза 4 закрыта, идёт полировка**. Пять локаций со своим декором, светом и
> механической особенностью; пять боссов с фазовыми боями и карточкой появления; 40 видов рыбы и
> 12 предметов мусора в трёх вариантах редкости; альбом с силуэтами; карта архипелага; ежедневные
> дела с серией дней; обучение первых десяти минут одной строкой; наведение крючка на видимую
> рыбу; серия уловов без обрыва; реклама и покупки по правилам площадки; навигация пультом;
> баланс боёв подогнан симулятором. В чек-листе модерации закрыто 54 пункта из 58.
>
> Осталось внешнее: живой плейтест и прогон на черновике в консоли разработчика.
> Журнал — [docs/spike-log.md](docs/spike-log.md).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 — сцена воды
npm run build      # typecheck + тесты + сборка в dist/
npm run test       # тесты пула заброса и баланса боя
npm run zip        # архив для консоли Яндекс Игр + проверка требований площадки
npm run capture    # полный цикл в Playwright: кадры в dist-shots/ + проверка консоли
npm run shot       # один кадр в файл: для работы над картинкой
npm run balance    # отчёт по балансу боёв: пять моделей игрока против всего каталога
npm run tune-fights # пересчёт длины боя и терпения по данным (правит src/content/*.json)
npm run promo      # иконка и обложка в dist-promo/
```

`capture` и `shot` требуют запущенного `npm run preview` в соседнем терминале; `promo` рисует
вектор и браузер поднимает сам.

Управление одним пальцем: **тянуть** — осмотр и руление крючком под водой, **удержать** — копить
силу заброса, **отпустить** — заброс, **удержать в бою** — подмотка, **тап** — действие.

- Грузило тонет, пока не упрётся в конец лески или в дно локации, — и клюёт там. Значит, глубина
  решает, кто попадётся: мелководная рыба ловится у поверхности, глубоководная только на длинной
  леске. Погружение ускоряется с глубиной: дно причала — шесть секунд, дно разлома — двенадцать.
- В верхних метрах плавает стая: подведите к рыбе крючок — она подсветится и клюнет именно она,
  не дожидаясь дна. Это быстрый улов вместо глубокого; тап сматывает заброс досрочно.
- Заброс подальше делает глубину меньше: леска — сфера с центром на вершинке удилища, и то, что
  ушло вдаль, не уйдёт вглубь. В бухте вдобавок сносит течением.
- В бою тяните на низком натяжении и отпускайте перед обрывом. На пределе полоса бьётся, снасть
  скрипит и даётся две десятых секунды, чтобы отпустить.
- Улов на настиле буянит — тапайте по нему, пока он не разнёс снасти.
- Каждый улов подряд добавляет +5 % к цене (не больше +50 %), обрыв обнуляет серию.

Задание от NPC ведёт цепочкой через все пять локаций: от «хоть что-нибудь» на причале до дна
разлома. Если цель водится не там, где задание выдано, локация названа прямо в заголовке — гадать,
почему рыба не клюёт, не придётся.

Внизу: кошелёк, кнопка звука, **«Карта»** с архипелагом, **альбом** со всеми видами и **«Снасти»** —
четыре ветки прокачки, приманка за ролик и блок покупок под отдельным заголовком, в этом порядке. Сверху — задание от NPC, по нему же открываются
ежедневные дела. После улова на несколько секунд появляется добровольное «Удвоить ×2»; на локальной
сборке вся реклама и покупки — заглушки.

На десктопе всё дублируется пробелом, стрелками и `R`; с пульта — Back для входа в меню и стрелки
для навигации. Отладка: `?q=low` — мобильный профиль качества, `H` — скрыть HUD, `L` — заморозить
главный поток на 250 мс для проверки устойчивости симуляции.

### Дев-страницы

Открываются в `npm run dev`, в сборку игры не попадают. Обе появились не для красоты: почти все
ошибки в моделях и значках нашлись именно тем, что вещи разложили рядом и посмотрели на них разом,
а не по одной в игре.

| Адрес | Что показывает |
|---|---|
| `/tools/models.html` | Модели улова: по представителю каждой формы плюс три редкости. `?all=1` — весь каталог и боссы, `?ids=angler,gulper` — названные виды крупно. Пробел включает вращение. |
| `/tools/icons.html` | Значки альбома для всех видов. `?unknown=1` — силуэты нераскрытых. |

## Промо-материалы

`npm run promo` рисует иконку и обложку вектором и кладёт в `dist-promo/` (PNG + SVG). Иконка и
обложка **не могут быть скриншотами** — это требование площадки, поэтому они нарисованы отдельно,
в том же языке форм, что и игра. Точные размеры площадка публикует не в документации, а в форме
черновика консоли, поэтому они параметры команды:

```bash
npm run promo -- 1024 1920 1080   # иконка 1024×1024, обложка 1920×1080
```

Скриншоты для карточки снимает `npm run capture`: там реальный геймплей, а для скриншотов он
как раз обязателен.

## Короткая версия плана

1. **Не портируем оригинал 1-в-1.** Из него берём кор-луп и комедийный хаос, вырезаем то, что не
   пройдёт модерацию Яндекса: алкоголь, азартные игры, огнестрел и жестокость к животным.
   Юмор при этом держится на механиках, а не на арте — см. [ADR-0003](docs/adr/0003-comedy-register.md).
2. **Формат:** полное 3D от первого лица (игрок стоит на причале), портретная ориентация на
   мобилках, управление одним пальцем. Сессия 3–6 минут, «ещё один заброс» как основной хук.
3. **Стек:** TypeScript + Three.js + Vite, вид от первого лица, собственная верле-физика лески
   как подача поверх детерминированной боевой системы. Игрок стоит на месте, поэтому
   управление остаётся одним пальцем — см. [ADR-0004](docs/adr/0004-first-person-3d.md).
4. **Монетизация:** rewarded-видео (×2 за улов, второй шанс, ежедневный сундук), межстраничная
   реклама между сессиями, детерминированные инаппы («без рекламы», стартовый набор).
5. **Сроки:** ~14–16 недель до релиза MVP командой 2–3 человека; вертикальный срез — к 6-й неделе.

Подробности — в документах выше.
